# Creature models

Put real Siegelings models here as `.glb` (preferred) or `.gltf`.

- **Name each file after the creature**: its `modelName` in `CreatureData.lua` (e.g. `Firsky.glb`) or its id (`firsky.glb`). Case doesn't matter.
- Creatures without a file keep their stand-in model, so you can add models one at a time.
- `manifest.json` is generated by `npm run dev` / `npm run build`; don't edit it.
- Size and facing follow the same `CreatureData.lua` fields as Roblox: `modelDisplaySize`, `modelScaleMultiplier`, `modelRotationY`, `modelStandUpAngles`, `modelPlacementYOffset`.
- Animations: a clip whose name contains `idle` plays at rest, and one containing `walk`/`run` plays while moving.
- Keep files small for the web (and phones): compress Meshy exports with
  `npx @gltf-transform/cli optimize in.glb out.glb --compress meshopt --texture-compress webp --texture-size 1024`.
  Meshopt-compressed files load without any extra setup.
